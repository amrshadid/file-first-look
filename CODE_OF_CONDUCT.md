# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and focus on what is best
for the people who use and build this project. Harassment of any kind is not tolerated.

To report unacceptable behaviour, contact the maintainers privately through GitHub. All
reports are reviewed and kept confidential.
